# تطبيق تحويل الكلام إلى نص - PRD

## المشكلة الأصلية
برنامج تحويل الكلام إلى نص مع إمكانية نسخ النص وتحريره وإضافة علامات الترقيم (فواصل، فارزات، أقواس)

## المستخدمين المستهدفين
- المستخدمين العرب الذين يحتاجون تحويل تسجيلات صوتية إلى نص مكتوب
- صانعي المحتوى والكتّاب
- المستخدمين الذين يريدون توثيق مكالمات ومحادثات

## المتطلبات الأساسية
1. تحويل الصوت إلى نص (Speech-to-Text) باستخدام OpenAI Whisper
2. تسجيل صوتي مباشر من المتصفح
3. رفع ملفات صوتية (MP3, WAV, M4A, WebM)
4. محرر نصي قابل للتحرير
5. أزرار علامات الترقيم العربية
6. نسخ النص للحافظة
7. حفظ النصوص في قاعدة البيانات
8. سجل النصوص المحفوظة
9. واجهة RTL عربية
10. وضع داكن/فاتح
