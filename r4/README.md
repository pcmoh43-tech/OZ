# مشاركة الطابعة عبر الشبكة

سكربتات جاهزة لمشاركة طابعة موصولة **بالسلك** على حاسوب واحد مع حاسوب آخر على **نفس شبكة الواي-فاي**.

## هيكل الملفات

```
printer-sharing/
├── windows/
│   ├── run.bat                    ← قائمة تشغيل (ابدأ من هنا)
│   ├── host-share-printer.ps1     ← الحاسوب الذي عليه الطابعة
│   └── client-connect-printer.ps1 ← الحاسوب الذي يريد الطباعة
└── linux/
    ├── run.sh                     ← قائمة تشغيل (ابدأ من هنا)
    ├── host-share-printer.sh      ← الحاسوب الذي عليه الطابعة
    └── client-connect-printer.sh  ← الحاسوب الذي يريد الطباعة
```

---

## Windows — خطوات سريعة

### 1. على الحاسوب الذي عليه الطابعة (Host)

1. انسخ مجلد `windows/` إلى الحاسوب
2. **انقر بزر الماوس الأيمن** على `run.bat` → **Run as administrator**
3. اختر **[1] الحاسوب المضيف**
4. اختر الطابعة من القائمة
5. اختر **نوع المشاركة**:
   - **أساسية** — شبكة محلية (موصى بها)
   - **كاملة** — جميع المستخدمين
   - **شركة/مجال** — Workgroup أو Domain
6. **احفظ** عنوان IP واسم المشاركة المعروضين

### 2. على الحاسوب الثاني (Client)

1. انسخ مجلد `windows/` (يمكنك نسخ `host-config.json` أيضاً لتسريع الإعداد)
2. **Run as administrator** على `run.bat`
3. اختر **[2] الحاسوب العميل**
4. أدخل **عنوان IP** للحاسوب الأول (أو استخدم الإعدادات المحفوظة)
5. اختر: طابعة افتراضية + صفحة اختبار

## Linux (Ubuntu) — خطوات سريعة

### 1. على الحاسوب الذي عليه الطابعة (Host)

```bash
cd printer-sharing/linux
chmod +x *.sh
sudo ./run.sh   # اختر [1]
```

### 2. على الحاسوب الثاني (Client)

```bash
cd printer-sharing/linux
chmod +x *.sh
sudo ./run.sh   # اختر [2]
```

## أنواع المشاركة

| النوع | الوصف | متى تستخدمه |
|-------|--------|-------------|
| **أساسية (Basic)** | شبكة محلية، اكتشاف تلقائي | المنزل أو مكتب صغير |
| **كاملة (Full)** | جميع المستخدمين على الشبكة | عدة أشخاص بدون حسابات |
| **شركة/مجال (Domain)** | Workgroup أو Active Directory | شبكات الشركات |

---

## نقل الإعدادات بين الحاسوبين

بعد تشغيل سكربت **Host**، يُنشأ ملف `host-config.json`. انسخه إلى مجلد `windows/` أو `linux/` على الحاسوب الثاني؛ سكربت **Client** سيكتشفه تلقائياً.

---

## استكشاف الأخطاء

| المشكلة | الحل |
|---------|------|
| الطابعة لا تظهر | تأكد أن كلا الحاسوبين على **نفس** شبكة الواي-فاي |
| Access denied | شغّل السكربت **كمسؤول** (Run as administrator) |
| لا يمكن الوصول للـ IP | أوقف VPN مؤقتاً؛ تحقق من جدار الحماية |
| Linux: CUPS لا يعمل | `sudo systemctl restart cups` |
| Windows: Execution Policy | السكربتات تستخدم `-ExecutionPolicy Bypass` تلقائياً |

---

## ملاحظات شبكات الشركات

- بعض الشركات **تمنع** مشاركة الطابعات بين الأجهزة
- إذا فشل الاتصال، تواصل مع **قسم IT**
- تأكد أنك **لست** على شبكة Guest WiFi

## المتطلبات

**Linux:** Ubuntu/Debian، CUPS، صلاحيات sudo
